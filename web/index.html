Pipeline

  1. In your browser: pdf.js or mammoth extracts the text and splits it into overlapping sections of about 1,500 tokens, with the same chunker the model was trained on.
  2. Cloudflare Worker: builds the fixed prompt and checks the daily budget.
  3. Modal GPU (L4): vLLM runs Qwen3.5-2B with the LoRA merged in. It returns each clause's type and its first and last words.
  4. Back in the Worker: those anchors are matched to exact character offsets, so highlights land on the real text.
  5. Ask embeds sections with bge-m3 and answers with Qwen3-30B-A3B on Workers AI, citing only sections it was given.

How your contract is handled

Your file
Read in your browser. The file itself is never uploaded.
Its text
Sent in sections to a Cloudflare Worker, then to a GPU on Modal (may run in the US) and, for Ask, to Workers AI. Processed in memory and not stored. Modal doesn't store the requests this app sends, and Cloudflare doesn't train on them.
Logs
One line per request: timings, counts, lengths and a keyed fingerprint. Never the text or your questions.
Your IP
Turned into a pseudonymous id, salted afresh each day, to enforce a fair daily quota. Deleted after the day.
Tip
Remove personal details before scanning a real contract.

Cost and limits

GPU spend is capped at $0.23 a day (under $10 a month). When it runs out, live scanning pauses until midnight UTC and the demos keep working. Scans are fast once the model is warm. The first scan after a quiet spell usually waits about 30 seconds for the GPU to start, and occasionally a few minutes.

The model has only been measured on CUAD: US commercial contracts filed with the SEC. Leases, employment contracts and non-US law are untested. Highlights can be wrong or missing.
